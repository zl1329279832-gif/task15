# 智慧泵站运行态势系统

基于 HTML5 Canvas 的智慧泵站可视化监控系统，纯前端实现，无任何第三方依赖。

## 运行方式

本项目为纯静态前端应用，以下任一方式均可运行：

**方式一：直接打开**
```
双击 index.html 即可在浏览器中运行
```

**方式二：本地 HTTP 服务**
```bash
# Python
python -m http.server 8080

# Node.js
npx http-server -p 8080

# VS Code
安装 Live Server 扩展，右键 index.html → Open with Live Server
```

浏览器建议：Chrome / Edge / Firefox 最新版。

## 交互说明

### 场景切换
顶部工具栏提供 5 种预设场景按钮：

| 场景 | 说明 |
|------|------|
| 正常运行 | 所有设备正常，水位正常 |
| 液位过高 | 进水池液位 92% 超限，告警触发 |
| 泵组故障 | 2# 水泵故障停机，1# 满负荷运行 |
| 传感器离线 | 进水压力传感器通信中断 |
| 夜间低负载 | 夜间场景，仅 1 台泵低速运行，画面变暗 |

切换场景后，以下元素联动变化：
- 设备状态颜色与标签
- 管道水流动画（故障/停机设备对应管道停止流动）
- 水池液位高度与颜色（高液位变红）
- 告警灯闪烁状态
- 底部告警列表
- 侧边数据面板数据

### 设备点击
点击画面中任一设备（水泵、阀门、传感器、电控柜、水池、告警灯），右侧滑出详情面板，展示：
- 设备名称与当前状态
- 流量、压力、液位、温度、能耗、运行时长等模拟数据
- 数据每 2 秒自动刷新

点击面板关闭按钮或按 `Esc` 键关闭面板。

### 告警栏
底部告警栏显示当前场景下的告警信息，点击标题栏可展开/折叠告警列表。告警分三级：
- 红色：错误（error）
- 橙色：警告（warning）
- 蓝色：提示（info）

## 设备状态

每个设备支持 5 种状态，对应不同颜色：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 运行 | 绿色 | 设备正常工作 |
| 停机 | 灰色 | 设备已关闭 |
| 故障 | 红色 | 设备异常，带闪烁效果 |
| 检修 | 橙色 | 计划维护中 |
| 离线 | 深灰 | 通信中断 |

## 模拟数据

系统使用 `config.js` 中的 `generateDeviceData()` 函数生成模拟数据，包含：
- **水泵**：流量(m³/h)、压力(MPa)、温度(°C)、功率(kW)、振动(mm/s)、运行时长(h)
- **阀门**：开度(%)、流量(m³/h)、压力(MPa)、运行时长(h)
- **传感器**：测量值、信号强度(%)、电池电量(%)、运行时长(h)
- **电控柜**：电压(V)、电流(A)、功率(kW)、温度(°C)、运行时长(h)
- **水池**：液位(%)、容量(m³)、水温(°C)

不同场景下数据范围自动调整（如夜间低负载时流量降低、故障时温度升高）。

## 场景配置

场景定义在 `config.js` 的 `SCENARIOS` 对象中，每个场景包含：
- `devices`: 各设备的目标状态
- `waterLevels`: 水池液位比例
- `alarms`: 告警消息列表

可通过新增 `SCENARIOS` 键值对扩展自定义场景，并在 `index.html` 中添加对应按钮即可。

## 性能优化

### 帧率节流
- 默认 30 FPS，通过 `requestAnimationFrame` + 时间差判断实现节流
- 自动检测帧率：连续 60 帧平均帧时 > 50ms 时自动降至 15 FPS
- 可通过 `renderer.setTargetFPS(fps)` 手动调整

### 离屏 Canvas 缓存
- 静态元素（背景、泵房建筑、管道管壁、电控柜外壳）绘制到离屏 Canvas
- 仅在场景切换等状态变化时重绘离屏层（`staticDirty` 标记）
- 每帧先拷贝离屏缓存，再叠加动态元素

### 对象复用
- 设备配置数组全局共享，不在渲染循环中创建新对象
- Canvas 状态通过 `save()/restore()` 复用，避免重复设置
- 事件处理器绑定一次，通过委托模式处理

### 资源释放
- `renderer.destroy()` 取消动画帧、移除事件监听、释放离屏 Canvas
- `engine.destroy()` 清除数据刷新定时器、清空设备 Map
- `ui.destroy()` 清除时钟定时器
- 页面 `beforeunload` 时自动触发全部清理

### DPR 限制
- `devicePixelRatio` 上限为 2，避免高 DPR 屏幕导致 Canvas 过大

### 渲染优化
- 管道水流使用 `lineDashOffset` 动画，比粒子系统开销极低
- 水泵叶片旋转使用 Canvas `rotate` 变换，无额外绘制开销
- 波浪效果使用简单正弦函数，步长 4px 减少计算量
