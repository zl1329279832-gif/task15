# 智慧泵站运行态势系统

基于 **HTML5 + CSS3 + 原生 JavaScript + Canvas 2D** 的智慧泵站可视化运行态势系统。纯前端实现，无需后端服务，打开浏览器即可查看。

---

## 项目结构

```
├── index.html          # 主页面（布局骨架）
├── css/
│   └── style.css       # 样式表（暗色主题 / 响应式）
├── js/
│   ├── data.js         # 模拟数据 & 场景配置
│   ├── renderer.js     # Canvas 2D 渲染引擎
│   └── app.js          # 应用控制器（交互 / UI 管理）
├── .gitignore
└── README.md
```

---

## 运行方式

本项目为纯静态前端，**无需安装任何依赖**。以下任选一种方式启动：

### 方式一：直接打开
双击 `index.html` 即可在浏览器中打开（推荐 Chrome / Edge / Firefox 最新版）。

### 方式二：本地 HTTP 服务器
```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx serve -l 8080

# PHP
php -S localhost:8080
```
然后在浏览器访问 `http://localhost:8080`。

### 方式三：VS Code Live Server
安装 **Live Server** 扩展，右键 `index.html` → Open with Live Server。

## 设备状态

每个设备可在以下 **5 种状态**之间切换（通过场景自动切换）：

| 状态     | 颜色     | 视觉表现                              |
|----------|----------|---------------------------------------|
| **运行** | 绿色     | 叶轮旋转 / 阀门开启 / 传感器波纹      |
| **停机** | 灰色     | 静止 / 阀门关闭                       |
| **故障** | 红色     | 红色 X 标记 / 高温指示                |
| **检修** | 黄色     | 扳手图标                              |
| **离线** | 暗灰     | X 标记 / 信号消失                     |

## 交互说明

### 1. 场景切换
画面底部有 **5 个场景按钮**，点击切换：

| 场景             | 效果                                                                    |
|------------------|-------------------------------------------------------------------------|
| **正常运行**     | 1#/2# 泵运行、3# 停机，液位 60%，无告警                               |
| **液位过高**     | 全部泵组启动，液位 92%，告警灯亮起，高液位报警                         |
| **泵组故障**     | 1# 泵故障停机，1# 阀联锁关闭，过流/过温告警                           |
| **传感器离线**   | 进水流量计 & 液位计离线（X 标记），自动模式降级                        |
| **夜间低负载**   | 仅 1# 泵低频运行，夜间暗色天空 + 星星，窗户亮灯                        |

切换场景时以下元素**同步变化**：
- 所有设备状态（颜色 / 动画 / 图标）
- 管道水流动画（部分管道停止流动）
- 水池液位（平滑过渡动画 + 波浪）
- 告警列表（分级显示：危急/预警/信息）
- 顶部统计数字（设备总数 / 运行数 / 告警数）
- 右侧数据面板（若已选中设备则自动刷新）
- 天空背景（日间 / 夜间切换）

### 2. 设备点击
- **点击**画布中的设备（泵 / 阀门 / 传感器 / 水池 / 电控柜 / 告警灯）
- 右侧面板显示该设备的详细信息：
  - 设备名称 & 当前状态
  - **流量** (m3/h)
  - **压力** (MPa)
  - **液位** (%)
  - **温度** (C)
  - **能耗** (kW)
  - **运行时长** (h)
  - 每项数据下方有**进度条**可视化
- 选中设备有**蓝色脉冲光环**标识
- 点击画布空白区域取消选中

### 3. 鼠标悬浮
- 鼠标移到设备上时，光标变为手型（pointer）

### 4. 数据自动刷新
- 设备数据每 **3 秒**自动刷新一次（模拟实时采集）
- 选中设备时面板数据同步更新

## 模拟数据说明

模拟数据定义在 `js/data.js` 中：

- **`dataRanges`**：每种设备状态下各指标的数据范围（最小值 / 最大值 / 单位）
  - 运行状态：流量 180-320 m3/h，温度 35-55C
  - 停机状态：流量/压力/能耗均为 0
  - 故障状态：温度 75-95C，压力异常
  - 离线状态：所有值显示 `--`
- **`generateData(state)`**：在指定范围内随机生成一组数据
- **`generateSceneData(sceneName)`**：为某场景所有设备生成数据快照

### 场景配置 (`scenes`)
每个场景包含：
```js
{
  label:        '场景名称',
  tankLevel:    0.60,          // 水池目标液位
  isNight:      false,         // 夜间模式
  equipment:    { /* 各设备状态映射 */ },
  activePipes:  [ /* 活动的管道 ID 列表 */ ],
  alarms:       [ /* 告警条目 {level, text, time} */ ]
}
```

## 性能优化说明

### 1. 帧率节流
- Canvas 动画目标帧率 **30 FPS**（而非 60 FPS），通过 `FRAME_INTERVAL` 控制
- 低性能设备上自动跳帧，不会累积延迟
- `deltaTime` 上限 100ms，防止长时间挂起后的突变

### 2. 对象复用
- 管道粒子不创建新对象，通过数学计算位置（`animTime * speed % totalLen`）
- 波浪动画使用固定段数（40 段）的 `Math.sin` 计算，无额外对象分配
- 命中区域预计算并缓存（`hitAreas` 数组），仅在 resize/场景切换时重建

### 3. 渲染优化
- Canvas 使用 `{ alpha: false }` 创建，跳过透明通道合成
- `devicePixelRatio` 上限为 2，避免超高分辨率屏幕的过度渲染
- 设备绘制使用简单几何图形（圆、矩形、线段），无复杂路径
- 夜间星星使用确定性位置（`(i * 137.5) % W`），无需存储数组

### 4. 资源释放
- `Renderer.destroy()` 方法：取消 `requestAnimationFrame`、清空引用、释放 Context
- `Renderer.stop()` / `Renderer.start()`：可随时暂停/恢复动画循环
- resize 事件使用 **200ms 防抖**，避免频繁重绘
- 数据刷新定时器可通过 `clearInterval` 清除

### 5. 内存管理
- 全部使用 **IIFE + 闭包**，无全局变量泄漏
- 设备数据按场景整体生成/替换，不保留历史
- 管道粒子无独立对象，仅用数学公式计算

### 6. DOM 优化
- DOM 引用启动时一次性缓存（`cacheDom()`）
- 面板内容使用 `innerHTML` 一次性更新，避免逐节点操作
- 告警列表 / 统计数据仅在场景切换时更新

### 性能参考

| 设备         | FPS    | CPU 占用 |
|--------------|--------|----------|
| 高性能 PC    | 30     | < 2%     |
| 中端笔记本   | 30     | 3-5%     |
| 低性能 PC    | 25-30  | 5-10%    |

## 技术栈

- **HTML5**：语义化布局、Canvas API
- **CSS3**：Flexbox 布局、CSS 变量、过渡动画、响应式断点
- **JavaScript (ES5)**：IIFE 模块化、requestAnimationFrame、事件委托
- **Canvas 2D**：几何绘制、渐变、阴影、裁剪路径、虚线

**零依赖**，不使用任何第三方库或框架。
